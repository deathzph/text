# 深拷贝与浅拷贝

浅拷贝（shallow copy）：只复制对象各成员的值。若成员是指针，复制的就是指针本身（一个地址），新对象与原对象的指针指向同一块内存。
深拷贝（deep copy）：复制对象持有的资源本身。为新对象另外申请一块内存，再把原对象内存里的内容逐份复制进去，两个对象各有一份独立数据。浅拷贝

浅拷贝复制的是“地址”，深拷贝复制的是“地址里的东西”。
```
浅拷贝：                     深拷贝：
stu1.scores ──┐             stu1.scores ──> [85, 90, 78]
              ├──> [85,90,78]              
stu2.scores ──┘             stu2.scores ──> [85, 90, 78]
   一块内存，两个主人            两块内存，内容相同
```
**对比**
|维度|浅拷贝|深拷贝|
|:---:|:---:|:---:|
|复制什么|成员的值|（指针=地址）|资源内容（新内存+内容）|
|内存关系|两对象共用一块|各自独立一块|
|改一方|另一方跟着变|互不影响|
|析构时|同一内存被释放两次 → 崩溃|各自释放各的，安全|
|谁提供|编译器默认生成|需手写（或依赖 string/vector 等）|
|开销|小（只复制指针）|大（要分配并复制内容）|
|适用|成员全是值类型，无动态资源|成员持有裸指针等动态资源|

## 关键认识
1. 对纯值类型，两者没有区别
2. 默认拷贝就是浅拷贝
   编译器自动生成的拷贝构造和拷贝赋值都是逐成员复制（memberwise copy），因此：类里有裸指针但没写拷贝构造，就是浅拷贝，析构时必然双重释放。
3. **判断标准**

|成员类型|默认拷贝安全吗|
|:---:|:---:|
|int、double|安全（值类型）|
|std::string、std::vector|安全（自带深拷贝）|
|裸指针 int*|不安全，必须手写深拷贝|
|shared_ptr|安全（有意共享，引用计数）|

4. 验证方法
   打印两个对象内部指针的地址：相同是浅拷贝，不同是深拷贝。再改其中一个对象的数据，看另一个是否跟着变。
